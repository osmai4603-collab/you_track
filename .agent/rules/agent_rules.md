# 🤖 agent_rules (قواعد الـ Agent في التخطيط والتنفيذ)

تحدد هذه القواعد التزامات الـ Agent عند بناء خطة تنفيذية أو تنفيذ مهام برمجية كبرى لضمان جودة الكود واتساق بنية المشروع.

---

## 🚫 1. قيد تهيئة المشروع (Initialization Constraint)
*   **يمنع** البدء في إعداد أي خطة عمل أو تنفيذ ميزة جديدة إلا **بعد التأكد من تهيئة المشروع بالكامل** باستخدام مهارة `تهيئة بنية المشروع (Project Structure Initialization)`.

## ⛓️ 2. القيود الصارمة للتنفيذ (Execution Strict Constraints)
*   **تحديد التبعات**: يجب تحديد كافة المهارات (Skills)، القواعد (Rules)، ومسارات العمل (Workflows) المطلوبة قبل البدء.
*   **اللغة العربية (إلزامية)**: يجب أن تكون كافة الخطط (Plans)، نصوص المحادثة، ملفات المهام، ومسارات العمل مكتوبة باللغة العربية حصراً.


---
> [!IMPORTANT]
> الالتزام بهذه القواعد هو الضمان الوحيد لاستدامة المشروع وجودة مخرجاته البرمجية.
