# 🎨 سير عمل: تهيئة الهوية البصرية الأساسية (Init Core Theme)

يحدد هذا السير الخطوات التسلسلية لتهيئة الهوية البصرية بالكامل لضمان اتساق التصميم ودعم الوضعين الفاتح والداكن.

### خطوات التنفيذ (Execution Steps):

1.  **بناء الألوان الخام**: 
    *   قم بتشغيل مسار العمل [/init_app_colors](init_app_colors.md).
    *   الهدف: تعريف درجات الألوان (CategoryColors) والوضعين الفاتح والداكن.

2.  **بناء مخطط الألوان**: 
    *   قم بتشغيل مسار العمل [/init_app_color_scheme](init_app_color_scheme.md).
    *   الهدف: ربط الألوان الخام بخصائص Material 3 (ColorScheme).

3.  **إعداد الخطوط وأحجامها**: 
    *   قم بتشغيل مسارات العمل [/init_app_font_sizes](init_app_font_sizes.md) و [/init_app_fonts](init_app_fonts.md).
    *   الهدف: تعريف خطوط المشروع (Inter, Tajawal) وأحجام النصوص القياسية.

4.  **بناء سمات النصوص**: 
    *   قم بتشغيل مسار العمل [/init_app_text_theme](init_app_text_theme.md).
    *   الهدف: تكوين الـ TextTheme الشامل للـ 15 نمطاً قياسياً.

5.  **تجميع الثيم النهائي**: 
    *   قم بتشغيل مسار العمل [/init_app_theme](init_app_theme.md).
    *   الهدف: تجميع كافة المكونات السابقة في كائن `ThemeData` واحد.

6.  **إضافة السمات المخصصة (اختياري)**: 
    *   قم بتشغيل مسار العمل [/init_theme_extensions](init_theme_extensions.md).
    *   الهدف: إضافة تأثيرات بصرية غير موجودة في `ColorScheme` مثل الظلال المعقدة.

---
> [!IMPORTANT]
> يجب اتباع هذا الترتيب بدقة عند تهيئة الثيم لأول مرة لضمان عدم وجود أخطاء في التبعات البرمجية.
