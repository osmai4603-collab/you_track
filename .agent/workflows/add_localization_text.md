# 📖 سير العمل: إضافة نصوص مترجمة (Add Localization Text)

يعتمد المشروع على ملفات `.arb` لإدارة النصوص المترجمة للغتين العربية والإنجليزية. اتبع الخطوات التالية لإضافة نص جديد:

## 📂 أولاً: التعديل على ملفات Arbs
1.  **اللغة الإنجليزية**: افتح `lib/core/localization/app_en.arb` وأضف المفتاح الجديد مع وصفه.
    *   *مثال*:
        ```json
        "save": "Save",
        "@save": {
          "description": "Text displayed on save button"
        }
        ```
2.  **اللغة العربية**: افتح `lib/core/localization/app_ar.arb` وأضف الترجمة المقابلة.
    *   *مثال*:
        ```json
        "save": "حفظ"
        ```

## 🏗️ ثانياً: توليد الكلاسات (Generation)
بعد تعديل الملفات، قم بتشغيل الأمر التالي لتبديل التغييرات في الكود البرمجي:
```bash
flutter gen-l10n
```
