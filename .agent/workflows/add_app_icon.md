# سير عمل إضافة أيقونة جديدة (Add App Icon)

اتبع هذه الخطوات عند الحاجة لإضافة أيقونة جديدة ليتم استخدامها في واجهات التطبيق، لضمان توافقها مع معايير المشروع.

## 📋 الخطوات الإجرائية

1.  **تحديد الأيقونة**: اختر الأيقونة المناسبة من مكتبة `Icons` أو من ملفات الـ `Assets`.
2.  **إضافة الأيقونة في `AppIcons`**:
    *   افتح الملف: `lib/core/constants/app_icons.dart`.
    *   قم بتعريف حقل ساكن (`static const`) باسم يعبر عن وظيفة الأيقونة (مثلاً: `addCircle`).
    *   قم بإعطائه قيمة الأيقونة المختارة.
3.  **مثال على الإضافة**:
    ```dart
    static const IconData addCircle = Icons.add_circle_outline;
    ```
4.  **الاستخدام في الـ UI**:
    ```dart
    Icon(AppIcons.addCircle)
    ```

---
> [!IMPORTANT]
> الالتزام بتعريف الأيقونات في كلاس واحد يسهل عملية تغيير هوية التطبيق البصرية لاحقاً من مكان واحد.
