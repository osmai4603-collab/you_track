# مهارة إدارة NotebookLM (NotebookLM Management)

استخدم هذه المهارة عند الحاجة لتثبيت أو تحديث أو حل مشكلات الاتصال بخادم NotebookLM MCP لضمان إمكانية الوصول إلى ملاحظاتك ومصادرك.

## 💡 متى وكيف تطلب استخدام هذه المهارة؟
*   **متى؟**: عند الرغبة في ربط NotebookLM بمساعدك الذكي، أو عند ظهور أخطاء المصادقة مثل `RPC Error 16: Authentication expired`.
*   **كيف؟**: اطلب "ثبت NotebookLM MCP" أو "حدث مصادقة NotebookLM".

## 🎯 الحاجة لهذه المهارة
تسمح هذه المهارة للمساعد الذكي بالتفاعل مباشرة مع NotebookLM، مما يتيح لك الاستعلام عن محتويات دفاتر الملاحظات، إنشاء ملخصات، أو إضافة مصادر جديدة مباشرة من بيئة التطوير.

## 🏗️ الخطوات الإجرائية

### 1. التثبيت والتهيئة (Installation & Configuration)
*   **التثبيت**: يتم استخدام Python لتثبيت الحزمة:
    `py -m pip install notebooklm-mcp-server`
*   **التهيئة**: إضافة الخادم إلى ملف `mcp_config.json` بالصيغة التالية:
    ```json
    "notebooklm": {
      "command": "py",
      "args": ["-m", "notebooklm_mcp.server"]
    }
    ```

### 2. المصادقة (Authentication)
هناك طريقتان للمصادقة:
*   **المصادقة التلقائية**: تشغيل الأمر `py -m notebooklm_mcp.auth_cli` واتباع التعليمات في المتصفح.
*   **المصادقة اليدوية (عند الفشل)**: استخراج ملفات تعريف الارتباط (Cookies) من المتصفح وحفظها يدوياً.
    *   [دليل المصادقة التفصيلي](resources/authentication_guide.md)

### 3. معالجة الفشل (Handling Failures)
**عند فشل المتصفح في الفتح أو فشل أداة `auth_cli` في الاتصال بـ Chrome Debugger، يجب بشكل قطعي تنفيذ الخطوات التالية:**
1. توقف عن محاولة المصادقة الآلية.
2. قم بطباعة "البرومبت المعتمد لطلب الكوكيز" (الموجود في دليل المصادقة التقني) للمستخدم ليعطيك البيانات يدوياً.
3. لا تحاول تخمين الكوكيز أو البحث في ملفات المتصفح عشوائياً.

### 4. الصيانة والتحقق (Maintenance & Verification)
*   **تحديث الرموز**: عند انتهاء الصلاحية، استخدم `mcp_notebooklm_refresh_auth`.
*   **التحقق**: استخدام أداة `mcp_notebooklm_notebook_list` للتأكد من نجاح الاتصال.

## ⚠️ تنبيهات هامة
*   تعتمد الجلسة على ملفات تعريف الارتباط لمتصفح Chrome/Edge.
*   في حالة ظهور `RPC Error 16` دائماً، يجب إعادة تشغيل عملية المصادقة (`auth_cli`).

## 📝 أمثلة
*   "حدث مصادقة NotebookLM": سأقوم بمحاولة تحديث الرموز من الكاش أو طلب تسجيل دخول جديد.
*   "افحص اتصال NotebookLM": سأقوم بسرد دفاتر الملاحظات للتأكد من أن الخادم يعمل.
